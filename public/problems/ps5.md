# PS5 — AI-Powered Personal Booking Agent using LangGraph

> **Domain:** LLM Agents / LangGraph / Scheduling Assistant / Tool Calling / Conversational AI

---

## Problem Statement

Design and develop an AI-powered **personal booking and scheduling agent** that can interact with users in natural language to manage meetings, appointments, and bookings. The agent should understand user intent, maintain conversational context, resolve scheduling conflicts, and confirm bookings using a structured, agentic workflow.

---

## Key Objectives

- Understand scheduling intents from natural language
- Maintain conversation state and user preferences
- Check availability using calendar data (real or mock)
- Handle conflicts and suggest alternative time slots
- Confirm and summarize bookings
